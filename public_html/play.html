Phantasia used to run inside your web browser as a Java applet. Browsers no longer run applets, so the game is now played with a small program you download once. It works on Windows, Mac and Linux.

1. Install Java

You need Java 8 or newer. If you don't have it, get the free installer from adoptium.net. On Windows you can also run winget install EclipseAdoptium.Temurin.21.JRE in PowerShell.

2. Download the client

Download phantasia-client.jar

3. Connect to the realm

The game server address is:

@@GAME_ADDRESS@@

Double-click phantasia-client.jar and enter that address when it asks. It remembers the address for next time.

If double-clicking does nothing, open a terminal (PowerShell on Windows) in the folder you saved it to and run:

java -jar phantasia-client.jar @@GAME_ADDRESS@@

4. Play

Click Sign Up to create an account, then Log In and make a new character. The number keys 1-8 press the buttons along the bottom and the numeric keypad moves you around the realm. New to Phantasia? Read The Rules first.
