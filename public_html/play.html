New here?

Click Sign Up to create an account, then Log In and make a new character. The number keys 1 to 8 press the buttons along the bottom, and the numeric keypad moves you around the realm. Read the guide to learn the ropes, and New in the Realm for gear, artifacts, daily quests, champions and world events.

Prefer a download?

The classic desktop client still works and connects to this realm by itself.

Windows

Download for Windows
About 45 MB. Java is included.

  1. Open the downloaded zip and click Extract all.
  2. In the extracted folder, double-click Play Phantasia.

If Windows shows "Windows protected your PC", click More info and then Run anyway.

Mac and Linux

Download the client
Needs Java 8 or newer.

Install Java from adoptium.net if you don't have it, then double-click phantasia-client.jar. If that doesn't work, run java -jar phantasia-client.jar in a terminal.

The game server address is @@GAME_ADDRESS@@ (the downloads already know it).
