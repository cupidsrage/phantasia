⚔  Play in your browser  ⚔

Nothing to install. Works on Windows, Mac, Linux, phones and tablets.

Prefer a program on your computer? The classic downloadable client still works:

Windows

Download Phantasia for Windows
(about 45 MB, Java is included)

  1. Open the downloaded zip and click Extract all.
  2. In the extracted Phantasia folder, double-click Play Phantasia.

That's it: the game connects to this server by itself. If Windows shows "Windows protected your PC", click More info and then Run anyway.

Mac and Linux

Install Java from adoptium.net if you don't already have it, then download phantasia-client.jar and double-click it. If double-clicking doesn't work, run java -jar phantasia-client.jar in a terminal.

The game server address is @@GAME_ADDRESS@@ (the downloads already know it).

Playing

New here or coming back? See New in the Realm for gear, artifacts, daily quests, champions and world events.

Click Sign Up to create an account, then Log In and make a new character. The number keys 1-8 press the buttons along the bottom and the numeric keypad moves you around the realm. New to Phantasia? Read The Rules first.
